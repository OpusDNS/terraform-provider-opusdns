# opusdns_vanity_nameserver_sets (Data Source)

Lists all vanity nameserver sets in the authenticated caller's organization (`GET /v1/vanity-nameserver-sets`). Results are auto-paginated by the SDK.

## Example Usage

```terraform
data "opusdns_vanity_nameserver_sets" "all" {}

output "vanity_set_names" {
  value = [for set in data.opusdns_vanity_nameserver_sets.all.sets : set.name]
}
```
