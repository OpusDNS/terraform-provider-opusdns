# opusdns_host (Data Source)

Reads a single OpusDNS host object (`GET /v1/hosts/{host_reference}`). Exactly one of `host_id` or `hostname` must be supplied.

## Example Usage

```terraform
# Look up a host object by id.
data "opusdns_host" "ns1_by_id" {
  host_id = "host_01jxxxxxxxxxxxxxxxxxxxxxxx"
}

# Or look it up by hostname.
data "opusdns_host" "ns1_by_name" {
  hostname = "ns1.example.com"
}

output "ns1_ips" {
  value = data.opusdns_host.ns1_by_name.ip_addresses
}
```

### Optional

- `host_id` (String) Host id (e.g. `host_01j...`). Mutually exclusive with `hostname`.
