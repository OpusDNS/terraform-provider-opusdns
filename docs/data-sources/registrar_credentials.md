# opusdns_registrar_credentials (Data Source)

Lists registrar credentials within the authenticated caller's organization (`GET /v1/connect/registrars`). Results are auto-paginated. The credential payloads themselves are never returned by the API and are not exposed here.

## Example Usage

```terraform
# List all registrar credentials in the organization.
data "opusdns_registrar_credentials" "all" {}

# Filter by registrar.
data "opusdns_registrar_credentials" "internetx" {
  registrar = "INTERNETX"
}

output "internetx_names" {
  value = [for c in data.opusdns_registrar_credentials.internetx.registrar_credentials : c.name]
}
```
