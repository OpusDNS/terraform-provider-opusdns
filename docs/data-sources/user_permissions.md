# opusdns_user_permissions (Data Source)

Reads a user's effective permission set (`GET /v1/users/{user_id}/permissions`). The OpenAPI spec leaves the response shape untyped, so callers get both a best-effort `permissions` list and the raw `permissions_json` body.

## Example Usage

```terraform
data "opusdns_user_permissions" "alice" {
  user_id = opusdns_user.alice.id
}

output "alice_permissions" {
  value = data.opusdns_user_permissions.alice.permissions
}
```
