# opusdns_domain_check (Data Source)

Performs a bulk domain availability check (`GET /v1/domains/check`). Unlike `data.opusdns_domain_availability`, this endpoint also returns premium-pricing info and TMCH claims keys, making it the preferred precondition for `opusdns_domain` registrations of premium or trademarked names.

## Example Usage

```terraform
# Bulk availability check with premium and trademark info.
data "opusdns_domain_check" "candidates" {
  domains = ["example.com", "example.org", "example.io"]
}

output "results" {
  value = data.opusdns_domain_check.candidates.results
}
```
