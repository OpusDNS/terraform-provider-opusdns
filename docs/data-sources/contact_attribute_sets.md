# opusdns_contact_attribute_sets (Data Source)

Lists contact attribute sets in the authenticated caller's organization (`GET /v1/contacts/attribute-sets`). Optional `tld` and `label` filters narrow the server-side query; results are auto-paginated.

## Example Usage

```terraform
# List all contact attribute sets for .de TLD.
data "opusdns_contact_attribute_sets" "de" {
  tld = "de"
}

output "set_labels" {
  value = [for s in data.opusdns_contact_attribute_sets.de.contact_attribute_sets : s.label]
}
```
