# opusdns_record (Resource)

Manages a DNS record set (RRSet) in an OpusDNS zone. Each resource represents all records for a given name and type within a zone.

## Example Usage

```terraform
resource "opusdns_record" "www" {
  zone_name = "example.com"
  name      = "www"
  type      = "A"
  ttl       = 300
  records   = ["1.2.3.4", "5.6.7.8"]
}

resource "opusdns_record" "mx" {
  zone_name = "example.com"
  name      = "@"
  type      = "MX"
  ttl       = 3600
  records   = ["10 mail.example.com.", "20 mail2.example.com."]
}

resource "opusdns_record" "txt" {
  zone_name = "example.com"
  name      = "@"
  type      = "TXT"
  ttl       = 300
  records   = ["v=spf1 include:_spf.example.com ~all"]
}
```

## Schema

### Required

- `name` (String) The record name relative to the zone (e.g., `www` or `@` for apex).
- `records` (List of String) The list of record data values (e.g., IP addresses for A records, hostnames for CNAME).
- `type` (String) The DNS record type (e.g., `A`, `AAAA`, `CNAME`, `MX`, `TXT`).
- `zone_name` (String) The name of the DNS zone that contains the record.

### Optional

- `ttl` (Number) The time-to-live in seconds. Defaults to `60`.

### Read-Only

- `id` (String) Unique identifier in the format `zone_name/name/type`.
