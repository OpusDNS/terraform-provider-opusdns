# opusdns_tag (Resource)

Manages a tag in OpusDNS. Tags categorize and group resources (domains, contacts, zones) and are surfaced across the API and console for filtering. Backed by `/v1/tags`.

## Example Usage

```terraform
resource "opusdns_tag" "production" {
  label       = "production"
  type        = "DOMAIN"
  color       = "color-3"
  description = "Tags production-tier domains."
}
```

## Schema

### Required

- `label` (String) Human-readable label for the tag.
- `type` (String) The resource category this tag applies to. One of `DOMAIN`, `CONTACT`, `ZONE`. This is immutable at the API level; changes force replacement.

### Optional

- `color` (String) The tag color palette slot. One of `color-1` through `color-10`. Computed by the server when omitted.
- `description` (String) Optional free-text description of the tag.

### Read-Only

- `created_on` (String) RFC3339 timestamp when the tag was created.
- `id` (String) The tag ID (mirrors `tag_id`).
- `object_count` (Number) Number of objects currently associated with this tag.
- `tag_id` (String) The unique identifier for the tag (e.g. `tag_01j...`).
- `updated_on` (String) RFC3339 timestamp when the tag was last updated.
